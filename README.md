# Robo Path 2

A 32-level coding and logic game for ages 5–6. Tap arrow blocks (and loop blocks) to program a robot 🤖 to collect coins 🪙 and reach the star ⭐.

- Sequencing, loops, planning ahead and debugging
- Boards grow from 5×5 to 7×7
- Progress saves in the browser
- Single file, no dependencies: open `index.html` in any browser
